# CUDA furnace: scoped homepage experiment

One billion distinct synthetic identifiers; three fields compared between fused
CUDA and an independent CuPy graph. Zero mismatches. GPU phase 2.5054812 seconds.
Complete GPU/database experiment 4.335778 seconds, excluding Python import/startup.
Timing is one measured run, not a multi-run benchmark distribution.

Separate actual SQLite fixture: one million rows, 31,473,664 bytes, 256 query
comparisons, three complete category walks. Nine Chrome prototype checks passed.
Four deliberate output corruptions detected. Injected failing receipt rejected.
No billion-case dumps retained. No confidential source inputs used.

These are compact receipts. Executable experiment sources remain in the owner's
local E-drive experiment folder and are identified by hashes; this publication
alone is not a self-contained reproduction package. The public receipt checker
requires those exact local files. No synthetic throughput claim establishes
billion-row hosting, production concurrency or physical-design correctness.

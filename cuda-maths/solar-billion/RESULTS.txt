THE DETERMINISTIC FORMULA  (full text in FORMULA.txt, coefficients in FORMULA.json)
  1  N_max = floor(1500 / (Voc x (1 + beta/100 x (Tdesign - 25))))
       Tdesign = Tmin + 10 on the allowance reading, Tmin without it. BOTH are printed.
  2  N_min = ceil(500 / (Vmp x (1 + gamma/100 x (Thot - 25)))).  Build N = min(34, N_max).
  3  Sp = floor(40 / (1.25 x Isc)) a tracker; fuses when Sp >= 3 or (Sp-1) x 1.25 x Isc > the module fuse rating.
  4  volt drop = Imp x R / Vmp_hot <= 1.5 %; monotone in home-run length, so the
       SHORTEST run in a band decides whether that band holds a design at all - no search.
  5  leapfrog-turned costs 1.09 m of lead for every 1 m of site cable it saves, so it never
       minimises METRES - but it deletes the site return run, so it wins on VOLT DROP
       whenever r_lead / r_site < 0.917, i.e. whenever the lead is a size up on the site
       cable. Screening sequential alone loses 411 of the 2520 cells; screening both loses none.
  PROOF  the rules reproduce the brute-force best modules-per-string in 2520 of 2520 cells (100.00%),

LIMITS
  - The cold-voltage clause is DISPUTED. BOTH readings are computed everywhere: reading A adds a +10 K allowance to the site minimum, reading B does not. A design that holds on A but not on B is returned as DISPUTED-COLD-VOLTAGE, never as a bare pass.
  - Module pitch, junction-box spacing 0.84 m, 0.1 m lead slack, the 0.63 m supplied lead pair and the 45 m mean home run are ASSUMED (from the bench), not measured.
  - Vmp temperature coefficient is ASSUMED equal to the published Pmax coefficient; no class publishes a Vmp coefficient.
  - Ampacity is NOT checked here: the volt-drop cap of 1.5 % binds before the current-carrying table on every conductor in this space.
  - The inverter backfeed contribution to a string fault is not published, so the fuse answer is the parallel-string term only.
  - No rating is claimed beyond the declared tables. No maker, model or price appears anywhere.
  - bifacial factor 1.0..1.2 is applied to Isc for the design current and to Imp for the loss terms; it is a declared input, not a measured gain.
  - CPU watts were NOT measured - no wall meter and no RAPL read on this machine.

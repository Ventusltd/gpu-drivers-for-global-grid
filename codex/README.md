# Local overnight review controller

This is orchestration, not an independent benchmark lane. It invokes the existing attributed Claude CPU/WebGPU harness unchanged, using installed Chrome headlessly because the bundled Chromium failed its driver-library probe on 2026-09-05. CPU-reference byte counts passed on the actual discrete adapter in Chrome.

Run `overnight.py --artifact <existing source export> --out <new offline folder> --hours 8`. Requires Python psutil and the existing Node/Playwright setup. It does not register a self-hosted GitHub runner or execute untrusted repository programs.

Useful queued work: each existing owner checkout produces a commit-pinned source-review cartridge and a short REVIEW.md. Queries identify parse failures, exact duplicate Git blobs, large modules, lexical imports and candidate extraction symbols. Largest eligible unique files are checked first, up to 240 per repo, at most 1 MB each. Vendor/data/results/archive exclusions and truncation are recorded. Dirty work is not reviewed or changed. Proposed extraction boundaries require human/agent review; these are evidence cartridges, not runnable application modules.

Hardware measurements run once per hour alongside that finite review queue. The controller leaves at least four logical cores outside its affinity, uses below-normal priority, scales worker count to current free RAM, pauses below 2 GiB available RAM and resumes only above 2.6 GiB. GPU work pauses at 78 C and cools to 70 C; at least 1 GiB VRAM and 5 GiB disk space must remain. AC disconnection pauses work. CPU package temperature is unavailable and explicitly unmeasured; this cannot guarantee against thermal throttling. The firmware's protections remain active. No power/clock/fan limits or sleep settings are changed.

Safety samples every five seconds plus sensor-query latency (up to five more seconds); hourly JSON summaries; one small review card per repo and REVIEW-INDEX.md for rapid triage. STOP file in the evidence directory ends this controller and its own children. Jobs time out after three minutes. Interrupted jobs are recorded individually and are not passes. Evidence stays offline, capped per partition; no file is intended to approach 50 MB. All files count toward the aggregate storage guard. The controller finishes after eight hours, or waits between hourly measurements after useful work is exhausted. It does not pad the queue with pointless repeated load. The controller requests that Windows remain awake while it runs (the display may sleep), releases that request on exit, and does not alter persistent power settings. Keep AC connected and avoid closing the lid if that suspends the laptop.
